## C. 점검 항목 (대표님 테섭 확인 대기 — 일부는 실제 데이터를 바꿉니다)

**저장 구조 통일**
- C1 Ph2·Ph4·청주 M15X의 홈·공정·출역·공수·일정·공사일보가 이전 전과 같은 값인지 (이전 검증: Ph2 공정율 10.93%, Ph4 27.27%)
- C2 공정 체크 하나를 눌러 저장되고 홈의 공정율이 바뀌는지
- C3 공사일보 저장 뒤 전자결재 업무일지가 생기는지 (B2)
- C4 설정 탭 — 기본정보 저장, 자동 공수, 참여자 지정, 종료 → 재개
- C5 프로젝트 주소 키가 바뀜(`#/pjt/reg_X` → `#/pjt/X`) — 북마크 다시 저장

**공정·PPT**
- C6 공정표 PPT를 Ph2·Ph4·그 밖 프로젝트로 만들어 구포털 PPT와 수치·모양 비교
- C7 W-OB 섹터 배치도에서 "좌표 번호 맞추기" 실행(이전 데이터 기준 다시 확인)
- C8 주간 공정회의 PPT를 구포털 PPT와 비교(도면·박스 색·표)
- C9 선택 기능을 켜고 다른 프로젝트에서 도면 이미지를 올려 배치
- C10 단계·품목 추가 후 영업기획 청구서의 공정 연동 반영

**일정·공사일보·홈**
- C11 일정 등록 후 포털 홈 통합 캘린더에 나오는지
- C12 공사일보 자동 채움, 근무시간 7가지 채움, 철야 인쇄본
- C13 옛 양식 일보 "새 양식으로 편집", 다른 사람 일보 수정 시 수정자 표시
- C14 프로젝트 홈(폰 포함), 홈 공정율 = 공정 탭 공정율

**근로자 연명부 (1~3단계)**
- C15 목록·상세가 구포털과 같은지(인원, 검진·교육 개수, 팀 구분)
- C16 인적사항 수정, 신규 등록 후 구포털에도 나오는지, 삭제
- C17 팀원이 있는 팀장을 퇴사·이동·삭제하려 할 때 막히는지
- C18 주민번호 [보기 (사유 선택)] — 열람 기록이 남는지
- C19 사진 올리기·보기·다운로드·교체·삭제 + 구포털에도 보이는지 + 폰 카메라·앨범 선택
- C21 건강검진 줄 추가·만료일 자동/수정됨/↺·결과 PDF 올리기·교체·삭제·내려받기(PDF 는 Storage 에 올라가므로 실제 파일로 확인)
- C22 사내화 교육 이수 체크·만료일, 업체 포털 계정(상생협력포탈·행복한 만남) 수정 후 구포털 연명부에도 같은 값으로 보이는지
- C23 자격·인증(유효기간→만료일 자동·수정됨), 법정교육(시공사×종류 누계가 구포털과 같은지) 수정 후 구포털에도 같은 값으로 보이는지
- C24 화학물질안전원: 교육 이력·연도별 이수 현황(연 2시간)·수료증 PDF 올리기/교체/삭제/내려받기·교육시스템 계정이 구포털과 같은지
- C20 밝은 테마·어두운 테마에서 모양, 폰에서 명단 → 상세 전환

## D. 알려진 한계 (고칠 때까지 그대로)
- 저장 구조 통일 이후 옛 화면(모바일 `m/`, 팀장 공수표 `team/`, 옛 영업기획 `gihoek/`, 옛 PJT 전체 홈·종료 PJT 목록)은 옛 위치를 읽어 **테섭에서 오래된 값**이 보인다. 본섭은 영향 없음.
- 연명부는 구포털 화면에 있던 입력 기능이 4단계까지 모두 새 화면에 있다. 아직 없는 것은 5단계(기존 인원 마이그레이션·월간 공수 보기)와 폰(m/) 전용 화면 — 상단 "구포털 연명부 열기"에서 입력.
- 로그인이 풀려 있으면 제가 실제 화면을 확인할 수 없다(대표님이 로그인해 주셔야 함).

# 급여·퇴직금 법정 기준 보정 설계서 (결정용)

작성: 2026-10-13 · 대상: 급여명세서(공제·소득세), 퇴직금 정산
**상태(2026-10-13 갱신)** — 대표님 결정 반영:
- ✅ **4대보험 연도별 요율표 + 급여명세서 양식 v7 구현**(이번 급여분부터 법정 요율, 저장 문서에 사용 요율 기록). 과거분(2026-01~09) 정산 방식은 공단 고지서 대조 후 결정.
- ✅ **근로자 명부에 공제대상 가족 수·8~20세 자녀 수·원천징수 비율 칸 추가**(관리자 입력, 저장만 — 간이세액표 도입 전까지 급여 계산에는 영향 없음).
- ✅ **퇴직금 보정 구현**: 임금총액=지급계(특별성과급 포함)·퇴직일=마지막 근무일 다음 날·월중 퇴직 일할·연간 상여/연차수당 3/12 가산·기술수당 포함 통상임금·지급기한 안내.
- ✅ **퇴직 시 미사용 연차 정산(참고) 카드**: 법적 퇴직일 기준 연차 현황의 구간별 잔여일 × 통상일급, 연차사용촉진 절차를 이행한 구간은 대상 제외, "연차수당 합계에 넣기" 버튼으로 평균임금 가산 입력에 반영(자동으로 넣지는 않음 — 퇴직 시 연차수당의 법적 처리는 노무사 확인).
- ⏳ 간이세액표 데이터 탑재(국세청 원본 파일 필요)·현장수당 통상임금 반영·노무사 검토는 남음.
이식 원칙상 새 화면은 구포털(테섭·본섭)의 계산을 **그대로** 옮겼다. 그 계산에는 이식 이전부터 있던 **법정 기준과의 차이**가 있어, 바꾸기 전에 결정이 필요한 항목을 정리한다. 수치는 웹 자료(출처 §8)로 확인했고, **실제 적용 전 공단 고지서·국세청 표·노무사 확인이 필요**하다.

## 2. 소득세 — 간이세액표

- 간이세액표는 **월급여액(비과세 제외) × 공제대상 가족 수(본인 포함) × (8~20세 자녀 수)** 로 정해지는 국세청 표(소득세법 시행령 별표 2). 2026.2.27 개정, **2026.3.1 이후 지급분부터** 적용(자녀 수별 추가 공제 신설).
- 검증한 표 한 줄(월 350만원 구간): 가족수 1/2/3/4/5/6명 = 127,220 / 102,220 / 62,460 / 49,340 / 37,630 / 32,380원. 현재 근사식은 같은 구간에서 **105,000원 고정**.
- 지방소득세 = 소득세 × 10%(원 단위 절사는 실무 확인).
- **필요한 것**: 근로자 명부에 `공제대상 가족 수`(본인 포함, 기본 1)·`8~20세 자녀 수` 칸 추가 → 급여명세서가 읽음.
- 구현 방식(선택):
  - **A. 공식 표 데이터 탑재(권장)**: 국세청 표를 데이터 파일로 넣고 월급여 구간·가족 수로 조회. 매년 2월 개정 때 파일 교체. 검증은 표의 임의 행 10여 개를 시험으로 대조.
  - B. 산식 구현: 별표 2의 계산식(근로소득공제·인적공제·보험료공제·세액공제)을 코드로. 표와 1원 단위로 안 맞을 수 있어 비권장.
  - (참고) 근로자가 80%·120% 원천징수를 신청한 경우는 별도 비율 칸.

## 4. 통상임금과 현장수당 방침(2026-10-01 결정)의 연결

- 대표님 결정: 현장수당은 **임금으로 인정(통상임금 포함)**, 매달 근무일수가 달라 **월별 실지급액 기준 통상시급**으로 계산, 연차 사용일·내근일은 미지급. 비포괄 전환 때 시급은 현행 포괄 연 총액을 동일하게 유지.
- 현재 시스템은 이 방침을 **담지 못한다**: 급여명세서에 "현장수당" 항목이 없고, 초과근로·퇴직금 통상임금은 **계약서 시급 하나**에서 나온다.
- 필요: ① 급여명세서 지급 항목에 현장수당(일수×직급별 단가) ② 통상시급 = (그 달 고정·일률 수당 합계)÷월 소정근로시간 ③ 초과근로수당·휴일근로수당·퇴직금 하한에 같은 통상시급 사용. (정책 시뮬레이션이 끝난 뒤 적용)

## 5. 이미 발행한 급여명세서의 처리 (결정 필요)

- 2026년 1월분부터 구요율(국민연금 4.5% 등)로 발행됐다면 **공제 과소**였다. 다만 **실제 4대보험 납부는 공단 고지서 금액**이 기준이라, 명세서와 고지서의 차이는 다음 중 하나로 정리한다: (a) 차액을 이후 급여에서 정산 (b) 회사가 부담(공제하지 않음) 결정 후 명세서 주석 — 근로자 동의·고지 필요.
- 확인 방법: 대표님이 최근 월 **공단 고지서 금액**과 명세서의 공제 4항목을 대조(각 항목이 몇 % 어긋나는지).
- 소득세는 가족 수 정보가 없어 현재 값이 실제 원천징수액과 다를 가능성이 크다 → 연말정산에서 정산되지만, 매월 명세서는 표 기준으로 바로잡는 것이 맞다.

## 6. 실행 순서 제안

1. **(코드, 결정 불필요 아님)** 연도별 4대보험 요율표 + 새 양식 v7(산출식 문구) — 적용 시작월 결정 후
2. 근로자 명부에 가족 수·자녀 수 칸 → 간이세액표 데이터 탑재 → 소득세·지방소득세 교체
3. 퇴직금: 임금총액=지급계로 전환(+연간 상여·연차수당 가산 입력) → 기준일·3개월 정의 확정 → 지급기한 안내
4. 현장수당·통상시급(정책 확정 뒤)
5. 모든 단계에 **시험**(공식 표·고지서 대조 값)과 **노무사 검토**

## 7. 결정 요청

1. **요율·소득세 정정의 적용 시작월**(2026-01부터 소급 안내 / 다음 달부터)과 §5 차액 처리 방식
2. **가족 수·자녀 수** 입력 방법(근로자 명부 칸으로 관리자가 입력 / 직원 본인 신고서)
3. 퇴직금: **임금총액 정의**(특별성과급 포함 여부)와 **퇴직일(마지막 근무일 다음 날) 기준**, 월중 퇴직 시 일할 3개월 계산을 할지
4. 노무사 검토 범위(퇴직금 산식·평균임금 정의·현장수당 통상임금 편입)

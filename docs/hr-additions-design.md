# 인사 추가 기능 설계안 (초안 r1 · 2026-10-16)

대상: 인사 모듈(테섭 구축 완료) — **본섭으로 넘기기 전** 추가. 사용자는 인사 권한자 4명(김종화·김민서·김영희·송지훈).
이 문서에는 개인 급여 금액·개인정보를 쓰지 않는다(공개 저장소).

## 0. 원칙
1. **클릭 몇 번**: 할 일 → 클릭 → 미리 채워진 화면 → 저장 → 다음 할 일. 입력은 최소, 계산·채우기는 포털이 한다.
2. **중복 금지**: 인사 홈 카드 4개(재직 인원·계약 갱신 D-30·급여명세서 미작성·이번 달 초과근로)·회사 조직도·재무회계 월간 수지는 다시 만들지 않고 링크·재사용한다.
3. **법정 서류는 추정 금지**: 자료가 없으면 "자료 없음"으로 비운다. 소급본에는 "복원본"과 출처를 표시한다.
4. **새 컬렉션은 관리자 전용**: 테섭 규칙에 관리자 전용 목록(`isAdminOnlyCollection`)으로 추가하고 규칙 시험 후 게시한다(전체 직원 허용 조항에 걸리지 않게).
5. **결정된 기준**: 입사일=엑셀 기준(제이에이치테크 법인 기준일), 사번=포털 기준, 4대보험 신고·입사 서류 체크리스트·퇴사 후속 서류·현장 배치 변경은 제외.

## 1. 월 마감 흐름 (허브)
인사 홈 맨 위에 **"이번 달 마감" 5단계 진행 바**. 각 단계 버튼이 해당 화면을 열고, 끝나면 다음 단계가 켜진다.

| 단계 | 하는 일 | 클릭 |
|---|---|---|
| ① 근태 확인 | 누락·근태 수정 요청 미처리 건수 표시 | 건수 → 해당 목록 |
| ② 급여명세서 일괄 작성 | 미작성자 목록 → 한 번에 생성(기존 급여명세서 계산 재사용) | "일괄 작성" |
| ③ 급여 마감 | 해당 월 급여명세서·근태 수정 잠금(해제는 관리자 사유 기록) | "마감" |
| ④ 임금대장 생성 | 월 임금대장 자동 작성(아래 2) | "생성" |
| ⑤ 월간 인사 보고서 | 화면+PDF·엑셀(아래 8) | "생성" |

데이터: `hr_month_close/{YYYY-MM}` = { 단계별 완료 시각·실행자, 마감 시각, 마감 해제 이력 }. 재무회계의 급여 가져오기는 ③ 이후 안내 링크만(이미 있는 기능).

## 2. 임금대장 + 급여 마감 (채택 ①)
**근거**: 근로기준법 제48조(임금대장 작성·3년 보존). 급여명세서는 개인별 문서이고 임금대장은 월 전체 일람이라 중복되지 않는다.
- **화면**: 월 선택 → 직원 행 표. 열: 성명·생년월일·입사일·직위/업무·근로일수·근로시간(연장·야간·휴일)·임금 항목별 금액·공제 항목별·실지급·지급일. 각 행에 **출처 배지**(포털 발행 / 엑셀 소급 / 장부 복원 / 자료 없음)와 **장부 대조 배지**(일치/차이). 엑셀·PDF 출력.
- **데이터**: `wage_ledger/{YYYY-MM}/rows/{rowId}`(관리자 전용, 마감 후 수정 불가).
- **포털 발행분**: 월 마감 ④에서 급여명세서 데이터로 자동 생성.
- **소급**: 아래 3 "엑셀 가져오기".
- **야간근로시간**: 엑셀에 칸이 없어 소급분은 비움("자료 없음"), 포털 발행분부터 근태에서 계산.
- **기존 관계**: `payslip.js`(개인 명세서) 데이터 재사용, 재무회계 급여 전표와는 대조만(쓰기 없음).

## 3. 급여명세서 엑셀 가져오기(소급)
- 임금대장 화면의 "소급 가져오기": **월별 `테크명세서양식(YY.MM).xlsx`를 여러 개 한 번에 선택** → 브라우저가 SheetJS로 읽음(서버 전송 없음).
- **미리보기·검산**(저장 전 필수): 지급합계=지급항목 합, 공제합계=공제항목 합, 실지급=지급−공제. 장부 전표(해당 월·직원)와 대조해 일치/차이 표시. 차이가 있으면 저장 차단 또는 사유 입력.
- **인적사항**: 입사일은 엑셀 값, 사번은 명부 값(명부 미등록 퇴직자는 사번 비움 + "명부 미등록(퇴직)" 표시). **계좌번호는 가져오지 않음.**
- **중복 방지**: 같은 월·직원이 이미 있으면 덮어쓰지 않고 건너뜀(교체는 별도 확인).
- 2024-11~2026-06(20개월)이 대상. 7·8월분과 `02. 공수`(공수표) 위치는 확인 필요.
- 시험: 실제 엑셀 2개로 만든 양식 fixture + 변조(합계 불일치·월 라벨 오류) 시험.

## 4. 주 단위 근로시간 모니터링 (채택 ②)
- **현재**: 월 소정근로·월 한도만 계산. **추가**: 근태 로그·공수에서 **주(월~일) 합계**를 계산해 44h·48h·52h 단계 경고.
- **화면**: 출퇴근 달력 위 "이번 주 N시간" 배지, 인사 홈 신호 칸, 클릭 → 그 주 일별 내역. 새 저장 없음(계산).
- 현장 야간·철야 규칙은 `work-shifts` 기준. 일 8h·주 40h 병행 판정은 **노무사 확인(의뢰서 6번)** 후 확정 — 그 전에는 경고만 표시하고 급여 계산은 바꾸지 않는다.

## 5. 수습·단기계약 → 정식 전환 (채택 ③)
- 근로자에 **고용 단계**(단기/수습/정규)와 종료·전환 예정일을 둔다(계약서 시작·종료일은 이미 필수).
- 종료 D-30·D-14 신호 → **"정식 전환" 한 번 클릭**: 정규 근로계약서·연봉계약서 초안(미리 채움) + 인사 변동 기록 자동 생성.
- 기존 "계약 갱신 D-30" 카드와 같은 방식으로 신호만 추가(카드 중복 없음).
- 사례: 10월 교육 근로 후 11월 정식 채용 예정 1건. 수습 기간 급여 감액 규정은 노무사 확인.

## 6. 인사기록카드 (채택 ④)
- 근로자 1명 화면: **타임라인**(입사·계약/연봉 변경·직급 변동·평가·면담·휴직·퇴직) + 현재 요약. 기존 컬렉션을 **읽기 전용으로 합쳐 보여 줌**(새 저장 없음, 필요 시 메모만 추가).
- 근로자 명부 상세에 "인사기록카드" 버튼. PDF 출력.
- 기존 관계: 명부 상세(현재 정보)·인사 변동(이력)·평가·면담이 흩어져 있어 한곳에서 보는 용도.

## 7. 연말정산 지원 (채택 ⑤)
- 1~2월: 직원별 공제자료 제출 요청(양식 폼) → 제출 현황표 → 세무 담당(김민서) 전달용 요약 엑셀. 연간 급여·4대보험 합계는 **임금대장에서 자동 집계**.
- 홈택스 신고·세무사 업무는 범위 밖. `연말정산` 폴더(OneDrive)는 양식 참고.
- **책임 분담 확인 필요**(세무 담당·세무사).

## 8. 월간 인사 보고서 (제안 ⑨)
- 월 마감 ⑤에서 생성(또는 매월 첫 영업일 초안 자동 생성 후 클릭 확정 — **방식 미정**).
- 내용: 인력 현황(7 축소안)·근태·초과근로·연차 소진·급여·인건비·계약 갱신·수습 종료·평가·면담·채용·**이번 달 조치 필요 목록**. 화면+PDF·엑셀. 기존 인사 홈 카드 데이터를 재사용.

## 9. 인력 현황 (축소안, 선택 ⑦)
- 새 것만: 직급·근속 분포·평균 근속, 입사·퇴직 추이, 월별 재직 인원 × 재무회계 인건비 = **1인당 월 인건비**(합계만, 개인별 금액 비노출, 관리자만). 막대·숫자 클릭 → 해당 명단.
- 뺄 것: 인건비 월별 추이 단독 그래프(재무회계 월간 수지에 있음), 계약 갱신·급여명세서 미작성·초과근로 신호(인사 홈 카드).

## 10. 개발 순서 · 본섭 영향
1. 규칙·데이터 모델(`wage_ledger`·`hr_month_close`·`yearend`) + 규칙 시험 → 2. 임금대장 + 소급 가져오기 → 3. 월 마감 허브 → 4. 주 근로시간 → 5. 수습 전환 → 6. 인사기록카드 → 7. 월간 보고서 → 8. 연말정산 → 9. 인력 현황.
각 단계마다 시험·테섭 배포·대표님 확인. 본섭에는 **새 컬렉션 규칙 게시와 화면 배포**(서버 함수 변경 없음 예정, 배포 자동화 ③ 이후 권장).

## 11. 확인이 필요한 것
- **대표님 결정**: ⓐ 급여 마감 잠금 정책(마감 후 수정 허용 범위) ⓑ 월간 보고서 생성 방식 ⓒ 인력 현황(⑦) 포함 여부 ⓓ 임금대장 대상 범위(급여명세서가 발행된 근로자) ⓔ 야간근로시간 입력 방법.
- **노무사**: 일/주 병행 연장 판정, 임금대장 소급 작성 형식, 근로자 명부 퇴직 후 3년 보존(명지훈·임현준 미등록), 수습 급여 감액.
- **자료**: 월별 `테크명세서양식` 엑셀 2~3개 샘플(24.11·25.07·26.06) — 파서 정확도용.

# 평가("내 평가") 배포 절차 — 대표님 작업 (테섭 먼저)

> 화면 코드는 춘식이가 테섭에 올렸습니다(빌드 20261015g). **아래 두 가지(보안 규칙 게시, 서버 함수 배포)는 대표님이 합니다.** 둘 다 테섭(`portal-test-6e0ff`)에서 먼저 하고, 본섭은 본섭 전환 날에만 합니다.
> 규칙을 게시하기 전에는 **내 평가가 동작하지 않습니다**(새 컬렉션 `eval_*`에 대한 규칙이 없으면 기본 규칙이 적용되는데, 이것이 **보안상 위험**합니다 — 아래 1번 참고).

## ⚠ 가장 중요한 주의 (춘식이가 시험으로 확인한 사실)
기존 규칙의 맨 아래에 `match /{document=**}`(그 밖의 모든 컬렉션: 승인된 직원이면 읽기·쓰기 허용)가 있습니다. **평가 규칙을 이것 "아래에 덧붙이거나", 이것을 그대로 둔 채 "위에 붙이면" 평가 보호가 모두 사라집니다** — Firestore 규칙은 여러 규칙 중 하나라도 허용하면 허용하기 때문입니다. 에뮬레이터로 실제 확인했습니다(김의 이름으로 윤이 평가를 쓰는 공격이 성공함).
그래서 **기존 규칙 3군데를 함께 고쳐야** 합니다. 아래 "수정 완료된 전체 파일"을 쓰면 됩니다.

### 방법 A (추천): 춘식이가 만든 "평가 추가본" 전체를 게시

이 파일은 **2026-10-13 테섭 백업을 기준**으로 아래 3가지만 바꾼 것입니다(나머지 규칙은 한 줄도 바뀌지 않았고, 사라진 규칙도 없음 — 비교 확인함).
1. `isEvalCollection()` 함수 추가
2. 맨 아래 `match /{document=**}`의 읽기·쓰기 조건에 `&& !isEvalCollection()` 추가
3. 평가 규칙 `match /eval_cycles`, `/eval_tasks`, `/eval_submissions` 추가

**게시 전에 반드시 확인하세요 — 10월 13일 이후 규칙을 바꾸신 적이 있으면 이 파일로 덮어쓰면 그 변경이 사라집니다.**
- 콘솔 → Firestore → 규칙 화면에서 **현재 규칙 전체를 복사해 메모장에 백업**
- 현재 규칙의 **줄 수가 408줄**이고 `edoc_drive`가 `isEdocCollection` 목록에 있으면 10월 13일 백업과 같을 가능성이 높습니다. 다르면 게시하지 말고 **현재 규칙을 춘식이에게 붙여 주세요** — 그 위에 같은 수정을 적용해 드립니다.

## 2. 서버 함수 `evalAct`
파일: **`edoc-functions-eval_20261015.zip`** (서버 코드 기준본은 비공개 저장소 `portal-functions`)

## 3. 평가 시작 전 준비 (포털 화면에서)
1. **직원 관리** → 인사총무팀 전원에게 **"인사평가"** 권한 체크(형일우 사원은 관리자가 아니라서 이 권한이 있어야 평가 운영이 보입니다)
2. **직원 관리** → PJT팀 **팀장** 지정
3. 평가 대상 직원이 **포털 계정과 근로자 명부가 연결**되어 있는지 확인
4. **평가 → 정기평가** 맨 위 **"평가 회차"** 카드(사장단 계정으로): 회차 만들기 → 시작 전 확인 항목 점검 → 과제 배정 → 평가 시작 → (직원 작성) → 평가 마감 → 동료평가 집계 → 결과 공개
- **마감한 회차는 다시 열 수 없습니다**(다시 열어 재집계하면 평균 변화로 개인 점수가 드러납니다).
- PJT팀이 **3명 미만**이거나 포털 계정이 없는 직원이 있으면 동료 평가자가 2명 미만이 되어 평균이 비어 있게 됩니다. 시작 전 확인 항목에 미리 표시됩니다.

## 4. 배포 후 확인 (직원 계정으로)
- 일반 직원 계정: 왼쪽에 **평가 → 내 평가**만 보이는가
- 사장단·인사평가 권한 계정: **평가 운영 → 정기평가·수시평가**가 보이는가
- 일반 직원이 주소창에 `#/eval/cycle`을 입력해도 **안내만 나오고 데이터가 안 보이는가**
- **인사총무 메뉴에서 정기·수시평가가 사라지고 "평가" 메뉴로 옮겨졌는가**(이번 배포로 위치가 바뀝니다)

## 5. 문제가 생기면
- 규칙 게시 후 다른 기능이 안 되면 → **백업해 둔 규칙으로 되돌리고** 춘식이에게 알려 주세요.
- 규칙 시험은 저장소 `tests/rules/`에 있습니다. 규칙을 바꿀 때마다 춘식이가 다시 돌립니다.

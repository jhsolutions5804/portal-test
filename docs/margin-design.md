# 프로젝트 마진율 계산 설계안 (r1 · 2026-10-16)

공개 저장소 문서이므로 금액·외부 정보 없이 **규칙만** 쓴다.

## 0. 목적
프로젝트별 **실현 마진율**을 자동으로 계산해 영업기획·월간 보고서(경영 층)·수시평가(프로젝트 성과)에서 같은 숫자를 쓰게 한다. 지금은 프로젝트 손익 = 청구 누계 − 지급 누계뿐이고, 견적에는 원가·실행예산이 없다.

## 1. 결정 사항 (대표님 2026-10-16)
| 항목 | 결정 |
|---|---|
| 전표 프로젝트 표시 | **운영 시작(A)** — 앞으로 매출·직접원가 줄은 프로젝트 필수, 과거 소급 |
| 원가 범위 | **ⓑ 직접원가 + 직접 노무비** (공통비 제외) |
| 마진율 식 | (청구 공급가액 − 직접원가 − 직접 노무비) ÷ 청구 공급가액 |
| 직접 노무비 배분 | 그 달 현장노무비(5110)를 **프로젝트별 공수 비율**로 배분 |
| 하루 분할 규칙 | 급여 직원이 하루 둘 이상 프로젝트 참여 시 **균등 분할 기본**, 쏠린 날만 **비율 수정** |
| 입력 위치 | **업무일지(공사일보 저장 화면)의 "오늘 참여한 프로젝트" 체크 칸** |
| 4대보험 | **요율로 계산한 사업주분을 추정 가산**, 보고서에 "추정 포함" 표시(세무사 확인 권장). 퇴직급여충당은 표시만 |
| 현장 비용 | 5110·5350은 공수 배분, 5010·5210·5310~5340·5390은 전표의 프로젝트 표시 그대로 |

## 2. 계산식
- **매출** = 해당 프로젝트 정산서 청구 공급가액 합(잠정 기본값).
- **직접원가** = 전표의 프로젝트 표시가 있는 5xxx 줄 합(5110·5350 제외).
- **직접 노무비** = Σ(월 5110·5350) × 프로젝트 공수 ÷ 그 달 전체 공수 + 4대보험 추정 가산(요율 × 배분된 임금).
- **마진** = 매출 − 직접원가 − 직접 노무비, **마진율** = 마진 ÷ 매출.
- 단계: 진행 중 누계 + 월별. 목표 마진율(프로젝트별 입력)과 비교해 차이를 표시.

## 3. 데이터
- **전표 줄 `pjt`**(이미 있음) + 과거 전표용 **분석 태그 오버레이**(`ledger_pjt_tags`, 금액·계정 불변, 전표 불변 원칙 유지).
- **일별 프로젝트 참여**: 업무일지 저장 시 "오늘 참여한 프로젝트" 목록과 비율(기본 균등) 저장(서버 판정). 외주 인원은 기존 공수표(출역) 사용.
- 월 마감: 프로젝트별 공수 합이 사람의 월 공수를 넘지 않는지 검산.

## 4. 열람과 보안
- 마진율·원가는 **경영 층**(영업기획, 사업본부 지정자). 프로젝트 화면에는 **금액 없이** 공정·출역·공수만.
- 개인별 급여·배분 금액은 노출하지 않고 **프로젝트별 합계**만 보인다.
- 새 컬렉션은 관리자·지정 권한 전용 규칙 + 규칙 시험.

## 5. 한계와 표시
- 공수 자료는 2026-06 이후만 있다 → 이전 구간은 **대표님이 비율을 직접 정하거나**(프로젝트가 여럿일 때) 단일 프로젝트면 전액 배정, 불가하면 "자료 없음" 표시.
- 4대보험은 **추정**임을 보고서에 표시. 퇴직급여충당은 마진에 미포함(표시만).
- 균등 분할은 한 달 합계로 보면 오차가 평균화되나 쏠린 날은 부정확 → 비율 수정으로 보완.

## 6. 개발 순서
1. 전표 프로젝트 표시 실행 항목(시드 91건·오버레이·소급 도구·가져오기 규칙·필수 입력·마감 경고) → 2. 업무일지 "참여 프로젝트" 체크 칸·일별 데이터 → 3. 마진율 계산 모듈(순수 함수+시험) → 4. 영업기획 프로젝트 상세에 실현 마진율·목표 대비 → 5. 월간 보고서 경영 층·수시평가 연결.

## 6-1. 견적 작성 도구와의 연결 (별도 항목)
견적 작성 화면을 **투입비 산출 계산기**(인원×단가×공수×할증×작업일수 ÷ 장비 대수)로 개편하는 항목이 대기열 1-2에 있다. 계산기의 단가는 **판매 단가**이므로 원가는 **별도 원가 단가**로 계산한다. 도구가 생기면 ①계획 공수·계획 생산성(수율 기준선) ②견적 단계 예상 마진 ③원가 달성률의 정식화(간이 역산 교체)가 가능하다.

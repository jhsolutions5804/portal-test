### 1-1 PJT 관리
- ☐ (설계안·결정) **자료 보관·PJT 파일 탐색기** — 직원 공용 원본=SharePoint 팀 사이트(PJT별 폴더), 백업·종료 PJT 보관=Backblaze B2(NAS 안 함), PJT 화면 오른쪽 파일 패널(웹에서 열기/앱에서 열기, 진행 중=SharePoint·보관=B2 전환), 포털 PJT 권한→SharePoint 한 방향 동기화(Entra 보안 그룹, 기존 portal-sync 앱), 패널은 Graph API 로 포털이 직접 그림, 모바일은 패널 없음(폴더 열기 링크만 검토), 직원은 B2 직접 접근 없이 포털이 창구. 규모: 원드라이브 약 60GB·외장하드 총량 미확인·종료 PJT 아카이브 4TB 기준. 외장하드 자료는 SharePoint로 한 번 옮기고 이후 보조용. **정할 것**: ① 패널을 새 3열 레이아웃 어디에 ② SharePoint 사이트·폴더 구조·Entra 권한(Sites.*) ③ 외장하드 이전 순서 ④ 종료 PJT 를 B2 로 보내는 시점
- ☐ (설계안) PJT 일정·현장 특이사항을 로그처럼 관리하는 notification 기능(대표님 10-06, 상세 미정)

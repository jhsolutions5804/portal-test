- ☐ (설계) **프로젝트 견적 대비 마진율 계산**(수시평가의 프로젝트 성과 평가용, 대표님 2026-10-15): 지금은 프로젝트 손익 = 청구 누계 − 지급 누계(공급가액)뿐이고 견적에는 원가·실행예산이 없음. 목표(계획) 마진율 입력, 실현 마진율 자동 계산, 직접 노무비(팀별 노무비)·직접비(전표 프로젝트 표시) 반영 단계 설계 필요 — 위 "전표 프로젝트 표시" 결정·1-3 공무(실행비) 기능과 연결 — **원가 범위 확정(2026-10-16, 대표님 "ㅇㅇ") = ⓑ 직접원가 + 직접 노무비**(공통비 배분은 제외, 회사 전체 손익에서 별도). 프로젝트 마진율 = (청구 공급가액 − 직접원가 − 직접 노무비) ÷ 청구 공급가액(매출 기준은 영업기획 청구 공급가액을 잠정 기본값). **재료 확인**: 장부에 **현장노무비 5110**(현장직 급여 총지급)이 이미 직접원가 계정으로 기록됨, 사무직 급여 6010 은 공통비. 월간 공수 자료는 2026-06 이후만 있음(본섭 `worker_manday`·`worker_attendance` 2026-06~09) → 2026-05 이전 배분 기준 별도 필요. **다음 질문: 노무비 배분 기준(월 공수 비율), 과거 구간 처리** — **배분 기준 확정(2026-10-16, 대표님 "일단 공수 베이스로 가")**: 직접 노무비 = 그 달 현장노무비(5110)를 **프로젝트별 공수 비율**로 배분. **대표님 제안("업무일지에 그날 참여한 프로젝트를 선택하게 하면 취합이 쉽지 않겠나, 특히 급여 주는 인원은 여러 프로젝트를 동시에 관리")**: **현황 확인** — ⓐ 업무일지 양식에 "프로젝트" 항목은 있으나 **문서 1건에 프로젝트 1개**(공사일보 저장 시 프로젝트별로 자동 생성) ⓑ 공수는 **날짜→사람→공수** 값이고 프로젝트마다 **별도 저장소**(Ph2 `worker_manday`, Ph4 `ph4_manday`, 경량 PJT 하위 `manday`) ⓒ **서로 다른 프로젝트 저장소가 같은 날짜에 겹침**(Ph2·Ph4 5일) → **한 사람의 하루를 프로젝트에 나누는 규칙이 없어 합이 1공수를 넘을 수 있음**(배분의 가장 약한 고리). 외주 인원은 공수표(출역)로, 급여 직원(여러 프로젝트 동시 관리)은 **"그날 참여 프로젝트 선택"**이 필요. **다음 질문: 하루를 프로젝트에 나누는 규칙**(균등 분할/비율 입력/시간 입력)과 입력 위치(업무일지 vs 공수표) — **하루 분할 규칙 확정(2026-10-16, 대표님 "ㅇㅇ")**: 급여 직원이 하루에 프로젝트 둘 이상 참여하면 **기본 = 균등 분할**(둘이면 0.5씩), 쏠린 날만 **비율로 수정 가능**, 입력 위치 = **업무일지(공사일보 저장 화면)의 "오늘 참여한 프로젝트" 체크 칸**. 외주 인원은 공수표(출역) 그대로. 한 달 합계는 프로젝트 합이 그 사람의 월 공수를 넘지 않게 검산. **다음: 직접원가 계정 중 노무 성격(공수로 배분)과 프로젝트 직접 지정 계정 구분** — **4대보험 통상 방식(2026-10-16, 대표님 "통상적으로 어떻게 하는데?")**: **일반 관행 = 포함** — 건설공사 원가계산은 노무비(직접+간접)에 더해 **경비로 사용자 부담 산재·고용·건강·연금·장기요양 보험료와 퇴직공제부금 등을 별도 계상해 원가에 포함**, 기업 실무의 프로젝트 원가도 직접 인건비를 **임금 + 사업주 부담 4대보험 + 퇴직급여충당(1/12)** 으로 잡는 것이 통상(가산률은 4대보험 사업주분 약 10% 안팎 + 산재 업종별, 퇴직급여 약 8.3%). **우리 장부 현황**: 사업주 부담 4대보험이 별도 비용 계정에 거의 없음(4대보험 납부 전표는 대부분 예수금(2030) 상계, 보험료 6110 은 4대보험 언급 1건뿐) → 장부 인건비가 실부담보다 작게 보임. **방안**: 가산분은 **포털의 4대보험 요율 함수(`insuranceRates`)로 계산한 추정치**를 직접 노무비에 더하고 보고서에 "추정 포함" 표시(세무사 확인 권장), 퇴직급여충당은

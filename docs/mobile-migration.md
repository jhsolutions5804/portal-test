# 모바일(m/) → 새 포털 통합 — 대응표 (2026-10-14 조사)

대표님 동의(2026-10-14): `m/` 를 새로 만들지 않고 새 포털(`app/`)로 통합한다. `m/` 는 구포털(`classic.html`)이 폰(User-Agent `Mobi`) 접속을 `m/home.html` 로 보낼 때만 열린다. 새 포털은 이런 이동이 없고 폰에서도 직접 쓰는 구조(하단 탭, 명단→상세 전환)다. 본섭 전환 때 진입점이 `app/` 이 되면 `m/` 는 도달할 수 없으므로 그때 폴더째 제거한다.

## 폰 실기 확인 목록(대표님 또는 현장 직원)
1. 새 포털 로그인 → 하단 탭(홈·전자결재·PJT·더보기) 이동
2. PJT: 전체 홈 카드·프로젝트 홈·출역 체크·공사일보 작성·일정 보기
3. 연명부: 명단 → 상세 전환, 사진 올리기(카메라/앨범)
4. 팀장: 내 팀 공수표(월 이동·개인 공수표·이미지 저장)
5. 조직도(m/admin 대응), 내 정보, 인사 화면

## 제거 시점
본섭 전환(A6)에서 진입점을 `app/` 으로 바꾸는 순간 `m/`·`team/`·`classic.html` 의 모바일 이동 코드는 쓰이지 않는다. 그때 `m/`·`team/` 를 제거한다(옛 저장 위치를 읽어 이중 집계를 일으키는 `team/` 포함).

# 본섭 반영 (2026-09-30)

> 대표님 지시 “그냥 자체 검증 결과를 믿을게. 진행해.” — 테섭에서 검증한 내 팀 공수표·PC/모바일 일치화·일정 통합·GUEST 제한을 본섭에 반영.

## 방식
- **파일을 통째로 복사하지 않고 3자 병합**(본섭 현재본 + 기준 원본 → 테섭 최신본의 내 변경분만 적용). 본섭 Firebase 설정과 본섭에만 있는 변경은 그대로 유지. 기준은 본섭 현재본과 가장 가까운 테섭 백업 원본(`prod_before`와 비교).
- 신규 `team/index.html`은 설정 블록 6줄만 본섭 값으로 치환.

## 폴더
| 경로 | 내용 |
|------|------|
| `prod_before/` | 반영 전 **본섭 원본** 11개 — 롤백은 이 파일로 되돌리면 됨 |
| `prod_after/` | 본섭 **배포본** 12개(`team/index.html` 포함) |
| `rules/prod_before.rules` | 반영 전 본섭 규칙(규칙셋 `fe8f68c2…`) |
| `rules/prod_after.rules` | 게시한 본섭 규칙(규칙셋 `6fe5d12a…`, 2026-09-30T16:18:32Z) |

## 병합 중 수동 해결한 충돌 3건
1. `index.html` 첫 줄 버전 주석: 본섭(`20260930h`)·테섭(`20260930m`)이 각자 이력을 덧붙여 충돌 → 양쪽 이력을 모두 살린 `20260930n`으로 통합.
2. `m/home.html` 근로자 연명부 카드(`rosterCard`): 본섭에 다른 작업이 만든 카드가 있었음. 대표님 결정(“연명부는 PJT 관리 하위”)에 따라 홈에서 제거하고, 표시 스크립트 한 줄도 정리. 연명부 진입은 `m/pjt.html`의 PJT 메뉴에 있음(본섭 연명부 2.2.1이 `back` 파라미터를 이미 지원).
3. `pjt_ph4/index.html` `_usSetDone`: 본섭에는 이 함수가 **없음**(테섭에만 반영된 미출시 “하루 넘기는 일정 완료체크 단일화”, SUP는 종료 프로젝트) → 미출시 기능은 가져가지 않고, 본섭에 있는 쓰기 함수 3개(`_usSave`·`_usDelete`·`_usUpdate`)에만 GUEST 차단 적용.

## 반영하지 않은 것 (의도)
- 규칙: 테섭에만 있는 **`edoc_*` 열람 제한 규칙**(`isEdocCollection`) — 대표님 결정 대기 항목이라 본섭에 넣지 않음. 본섭 규칙 = 본섭 현재 규칙 + `team_rates` + 일정 규칙.
- `pjt_roster`(연명부): 본섭이 이미 2.2.1(다른 작업, 팀장 계정 연결·모바일 카드·뒤로 가기 포함) — 손대지 않음. 월간 공수 안내 페이지 2개도 본섭에 이미 반영돼 있어 대상 제외.

## 규칙 게시 중 잡은 결함
본섭 최종 규칙을 조립할 때 `team_rates`를 **포괄 규칙 제외 목록에 넣는 것이 빠져** 있었음(테섭에는 있었음). 규칙은 OR 평가라 개별 규칙이 있어도 포괄 규칙이 승인 직원 전원에게 다시 열어 줌 → 게시 전에 발견해 추가, 게시본 기준으로 시험 재확인(계정·비밀번호·팀 단가 32).

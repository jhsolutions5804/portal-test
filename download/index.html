🖥️ Windows 데스크톱 앱 이용 가능

사무실 PC · 노트북용 설치 프로그램
⬇️ 다운로드 (JH-Portal-Setup.exe)
설치 방법
1. 위 버튼으로 다운로드 후 실행
2. "Windows의 PC 보호" 경고가 뜨면 추가 정보 → 실행 클릭 (정상 프로그램입니다)
3. 설치 완료 후 바탕화면 아이콘으로 실행

📱 Android 모바일 앱 이용 가능

안드로이드 휴대폰용 설치 파일(APK)
⬇️ 다운로드 (JH-Portal.apk)
설치 방법
1. 위 버튼으로 다운로드 후 파일 탭
2. "출처를 알 수 없는 앱" 경고가 뜨면 설정 → 이 출처 허용 후 설치 진행 (정상 앱입니다)
3. 설치 완료 후 홈 화면 아이콘으로 실행

📱 iPhone (아이폰)

앱스토어 없이 무료로 홈 화면에 아이콘 설치
🌐 포털 열기 (Safari로 접속)
설치 방법
1. 아이폰 사파리(Safari)로 위 버튼 눌러 포털 접속
2. 하단 공유 버튼 탭 → "홈 화면에 추가" 선택
3. 바탕화면에 생긴 아이콘으로 앱처럼 실행

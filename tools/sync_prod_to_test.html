🔄 본섭 → 테섭 데이터 동기화

본섭(프로덕션) 데이터를 테섭(portal-test)으로 완전히 거울 복사합니다. 테섭에만 있는 여분 데이터는 삭제됩니다.
⚠️ portal_users(로그인 계정)는 동기화 대상에서 제외됩니다 — UID가 프로젝트별로 달라서 그대로 복사하면 테섭 로그인이 전부 깨집니다.
⚠️ workers.portalUid 필드는 복사하지 않습니다 — 테섭에 기존 값이 있으면 유지하고, 없으면 비워둡니다.
⚠️ 이 작업은 테섭 데이터를 되돌릴 수 없이 덮어씁니다. 실행 전 정말 필요한지 확인해주세요.
⚠️ 날짜별로 이름이 바뀌는 컬렉션(daily_reports_YYYYMMDD 등)은 목록 조회가 불가능해 자동 동기화 대상에서 빠져있습니다.
